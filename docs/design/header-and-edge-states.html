Button-press pills

Each press flashes a pill in the header's right slot. A tap recalls a preset (brief green flash); holding OVERRIDE while you tap saves the current position — which triggers the full-screen confirmation in the next section.

OVERRIDE held — red, driving the PROGRAM camera

Tap a preset — RECALL (green flash)

Idle — status pills showing

Maps to PIN_OVERRIDE, PIN_RECALL_1, PIN_RECALL_2. Override is held (red while driving live). Tap = recall; OVERRIDE + tap = save → full-screen popup. Pill text is the same size as ON AIR now.

Edge states — fixed

Distinct full-screen layouts. Setup + Connecting/Lost share the amber "you need to do something / hang tight" language; hard failures go red.

~2.5s takeover after OVERRIDE + tap. Shows the camera and the saved P/T/Z position, then the console returns. The control loop keeps running underneath.

On "network lost": the firmware doesn't time-out to the AP after a drop — if Wi-Fi was working it just retries forever (restart to reconfigure). So there's no separate red "lost" screen with a countdown; the Connecting screen simply reads Reconnecting… when it had a link before. Faithful to the code, same as our rule for the ATEM sim.
